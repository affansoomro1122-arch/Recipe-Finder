# Recipe-Finder
This Web App is designed on finding the recipes about Food and also in Future it will be Shift in Online Restaurant Order Booking Full Functioanl App.

**Api For Search Bar**: https://www.themealdb.com/api/json/v1/1/search.php?s=${encodeURIComponent(recipeName)}
**Api For Recipe Id**: https://www.themealdb.com/api/json/v1/1/lookup.php?i=${id}
